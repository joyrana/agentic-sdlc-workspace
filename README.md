# Agentic SDLC Workspace

A skill-based workspace that takes business requirements through planning, architecture,
implementation, independent verification, human approval and controlled deployment — with
humans holding authority over every consequential decision.

The implementation arrives through one pull request per phase:

1. Workspace foundation
2. Business Analyst and skills
3. Planning and token-aware routing
4. Architecture and human approval
5. Developer agent
6. BA verification and QA
7. Governed shipping
8. Agent evaluation and optimization
